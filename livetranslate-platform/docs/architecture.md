```
┌─────────────────────────────────────────────────────────────┐
│                      用户浏览器                               │

│  └──────────────┘  └──────┬───────┘  └──────┬───────┘       │

                            │                  │

│                      网关服务器               │               │

│  │  - 请求日志                        │  │ - HTTP API      │  │
│  └────────────────────────────────────┘  └─────────────────┘  │

│  │       Translate Service            │                       │
│  │  - 接收文本                        │                       │
```

## 2. 模块职责

| 模块 | 职责 |
|------|------|
| common-core | 异常、常量、工具类 |
| common-web | 统一响应、全局异常处理 |
| common-redis | 会话缓存 |
| common-websocket | WebSocket 会话管理 |
| common-security | API Key 认证 |
| gateway-service | API 网关路由 |
| asr-service | ASR 语音识别 |
| translate-service | 文本翻译 |
| auth-service | 认证中心 |
| desktop-lyrics | 桌面字幕 |

## 3. 技术栈

- Java 17
- Spring Boot 3.2.0
- Spring Cloud 2023.0.0
- Spring Cloud Alibaba 2023.1.1.0
- MyBatis-Plus 3.5.5
- Nacos 配置中心
- Docker 部署

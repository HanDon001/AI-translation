# LiveTranslate 后续开发计划

## 当前状态 (v2.0.0)

项目已完成基础同声传译能力：英文语音 → DashScope ASR 识别 → Qwen-Plus LLM 翻译 → 中文输出，支持 Web 控制台 + 桌面悬浮字幕双端显示。

**已实现：**
- 实时语音识别与流式翻译
- 上下文感知（最近 2 句消歧）
- 桌面悬浮字幕（PyQt5 置顶窗口）
- 专业术语表（缩写自动转换）
- 一键启动脚本（start.bat）

**当前局限：**
- 共享 ASR 连接，多用户共用一条线路，互相干扰
- 无用户身份，无法保存个人偏好配置
- 翻译结果广播给所有客户端，无法按需定向

## Phase 1：用户系统 (v2.1)

**目标**：建立用户身份体系，让每个用户有自己的账号和偏好配置。

| 功能 | 说明 |
|------|------|
| 用户注册/登录 | 用户名 + 密码注册，JWT Token 认证 |
| 个人配置保存 | 语言偏好、API Key、术语表绑定到用户 |
| 翻译历史记录 | 每次翻译自动归档，支持搜索和导出 |
| 登录态持久化 | Token 刷新机制，7 天免登录 |

**数据库**：SQLite（开发）/ PostgreSQL（生产）

**API**：Auth Service（注册/登录/Token 签发）、User Service（配置/历史 CRUD）

**前端**：新增登录/注册页面，控制台上方显示用户信息和配置入口

---

## Phase 2：会话隔离 (v2.2)

**目标**：每个用户拥有独立的 ASR 会话，翻译互不干扰。

| 功能 | 说明 |
|------|------|
| 独立 ASR 连接 | Gateway 按 userId 分配专属 ASR 连接，不再共享 |
| 定向推送 | 翻译结果只推送给对应用户，不再全局广播 |
| 桌面字幕登录 | 桌面字幕窗口绑定用户 token，自动加载个人配置 |
| 管理员面板 | 查看在线用户数、ASR 连接数、API 调用统计 |

**架构变化**：

```
当前: Gateway → 1条共享 ASR 连接 → 广播全体
之后: Gateway → N条独立 ASR 连接 → 定向推送对应用户
```

## Phase 3：客户端实时互译 (v3.0)

**目标**：两人对话，各自获得独立方向的实时翻译。

### 场景

```
用户A (说英文)                    用户B (说中文)
     │                                │
     │   "Hello, how are you?"        │
     │────────────────────────────────▶│
     │                                │
     │              中文语音合成 ←─────┤
     │         "你好，你怎么样？"       │
     │                                │
     │         "我很好，谢谢！"          │
     │◀────────────────────────────────│
     │                                │
     │  "I'm fine, thank you!"       │
     │───── 英文语音合成 ──────────────▶│
```

### 技术方案

```
┌────────────────────────────────────────────────┐
│               Translation Room                  │
│                                                 │
│  ┌──────────┐                    ┌──────────┐   │
│  │ 用户 A   │                    │ 用户 B   │   │
│  │ 源: en   │                    │ 源: zh   │   │
│  │ 目标: zh │                    │ 目标: en │   │
│  └────┬─────┘                    └────┬─────┘   │
│       │                               │         │
│       ▼                               ▼         │
│  ┌─────────┐                    ┌─────────┐     │
│  │ASR(en)  │                    │ASR(zh)  │     │
│  └────┬────┘                    └────┬────┘     │
│       │                               │         │
│       ▼                               ▼         │
│  ┌─────────┐                    ┌─────────┐     │
│  │MT(en→zh)│                    │MT(zh→en)│     │
│  └────┬────┘                    └────┬────┘     │
│       │                               │         │
│       ▼                               ▼         │
│  推送给 B                        推送给 A        │
│                                                 │
└────────────────────────────────────────────────┘
```

| 功能 | 说明 |
|------|------|
| 翻译房间 | 创建/加入房间，房间内用户独立翻译方向 |
| 语音合成(TTS) | 翻译结果转为语音输出，解放双眼 |
| WebRTC 音频传输 | 浏览器之间点对点低延迟音频传输 |
| 状态同步 | 房间内用户在线状态、说话状态实时同步 |
| 文字字幕 | 除语音外同步显示文字翻译结果 |

## 其他后续优化

| 方向 | 说明 | 优先级 |
|------|------|--------|
| 离线模式 | 本地 Whisper 模型 + Ollama 翻译，不依赖云端 API | 低 |
| 流式翻译输出 | 翻译结果边生成边显示，不等 LLM 全部生成完 | 中 |
| macOS 桌面字幕 | 当前桌面字幕仅验证 Windows，适配 macOS | 低 |
| 移动端 App | React Native 或 Flutter 移动端 | 低 |
| 术语表社区共享 | 用户可分享和导入他人的术语表 | 低 |
| 多语言识别切换 | 自动检测源语言，无需手动选择 | 中 |
| 翻译质量反馈 | 用户对翻译结果评分，用于优化 prompt | 中 |
